## 1.4.7 — 2026-10-28
- 자동 점검이 LG 를 부르는 횟수를 크게 줄임: 5분마다 깨어나지만 LG 는 «방의 일정 시작 60분 전(또는 미리 켜는 시간 중 긴 쪽)부터 종료 후 정리까지» 30분마다 한 번, 그리고 중요한 순간(미리 켜기 시작·시작·종료 후 끄기)에만 호출. 일정 없는 시간대는 LG 호출 0회

## 1.4.6 — 2026-10-28
- LG 호출 한도(오류 1314) 대응: 기기 상태를 KV 에 90초간 저장해 여러 화면이 같이 사용, 새로고침 버튼은 20초 이상 지났을 때만 LG 를 다시 호출, 자동 갱신 60초→120초, 제어 직후에는 새로 읽음
- LG 가 한도 오류를 내면 이전 값을 «N초 전 값»으로 보여주고, 저장값이 없으면 친절한 문구 표시
