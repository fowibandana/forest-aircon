# 산림치유센터 냉난방관리 — 서버 + 폰·컴퓨터 화면

- **폰 화면** (`public/index.html`): 층별(B1·1F·2F) 방 카드. 방 온도, 오늘 일정(진행 중/다음), 에어컨 상태, 냉방·난방·끄기·온도 조작.
- **서버** (`src/`): 5분마다 주간운영계획 일정을 읽고, 시작 30분 전부터 방 온도를 봐서 에어컨을 켜고 끄고, 모든 일정이 끝나면 끕니다.
- ThinQ 앱의 «방 설정»은 API로 읽을 수 없어서, 에어컨 이름 → 방 대응표를 `src/rooms.js`의 `ALIAS_PLACE`에 옮겨 두었습니다.
  새 에어컨을 등록하면 거기에 한 줄을 추가하세요. (표에 없는 에어컨은 화면 맨 아래 «표에 없는 에어컨»에 나옵니다)

## 배포 (Cloudflare)
1. Cloudflare 대시보드 → **Workers & Pages → Create application → Import a repository**(GitHub) → 이 저장소 선택
2. **Root directory**: `forest-aircon-server` / Deploy command: `npx wrangler deploy` → **Save and deploy**
3. 배포가 끝나면 **Settings → Variables and Secrets**에서 **Secret**으로 두 개를 추가
   - `THINQ_PAT` : ThinQ 토큰 (재발급한 새 토큰)
   - `APP_PASSWORD` : 폰 화면에 들어갈 비밀번호 (직접 정하세요)
4. 주소(`https://forest-aircon.○○○.workers.dev`)를 폰에서 열고 비밀번호 입력 → 홈 화면에 추가

## 자동 제어 켜기
처음에는 `wrangler.toml`의 `AUTO_MODE = "dry"`(시험 모드)입니다. 실제로 제어하지 않고, 하려던 일을 화면의 «지금 판단»과 Cloudflare 로그에만 남깁니다.
며칠 지켜본 뒤 `"live"`로 바꾸면(GitHub에서 파일 수정 → 자동 재배포) 실제로 제어합니다.

## KV 연결 (방별 설정 저장 + 자동 제어 일시중지)

방마다 바꾼 자동 제어 기준과 «일시중지» 스위치는 Cloudflare KV에 저장됩니다. 연결하지 않으면 화면의 «자동 설정»에서 저장이 안 되고 기본값(src/config.js)만 쓰입니다.

1. Cloudflare 왼쪽 메뉴 «Storage & Databases → KV» → «Create» → 이름 `forest-aircon-state`
2. 만들어진 KV의 **ID**를 복사
3. (연결 완료: `wrangler.toml`에 KV `forest-aircon-state`가 이미 들어 있습니다. 다른 계정에서 새로 배포하면 그 계정의 KV ID로 바꾸세요.)

## 기준값 (src/config.js — 제가 임의로 정한 기본값)
| 항목 | 기본값 |
|---|---|
| 프로그램 시작 몇 분 전부터 제어 | 30분 |
| 방 온도가 이 이상이면 냉방(24°) | 26° |
| 방 온도가 이 이하면 난방(22°) | 18° |
| 냉방 중 이 이하로 내려오면 끔 | 24° |
| 난방 중 이 이상으로 오르면 끔 | 22° |
| 모든 일정 종료 후 끄기까지 | 10분 |
| 자동 제어 시간대 | 06:00~22:00 |

## 비밀번호 (APP_PASSWORD)

- 반드시 종류를 **Secret**으로 넣으세요. «Variable»로 넣으면 화면에 그대로 보이고, 다음 배포 때 지워질 수 있습니다.
- 여러 사람이 각자 다른 비밀번호를 쓰려면 한 칸에 쉼표로 구분해서 넣습니다. 예: `kim7Rain!, park3Cloud!, lee9Sun!` (비밀번호 안에 쉼표는 쓸 수 없습니다.)
- 누군가 그만두면 그 사람 것만 지우고 Deploy 하면 됩니다.
- 4자리 숫자 같은 짧은 비밀번호는 피하세요. 주소를 아는 사람이 계속 시도해 맞출 수 있습니다.

## 앱으로 설치 (폰·컴퓨터)

같은 주소를 폰과 컴퓨터에서 «앱»처럼 설치해 쓸 수 있습니다(설치형 웹앱, PWA). 별도 APK는 필요 없습니다.

- 폰(안드로이드 크롬): 주소 열기 → 메뉴(⋮) → «홈 화면에 추가» 또는 «앱 설치»
- 컴퓨터(크롬/엣지): 주소창 오른쪽의 설치 아이콘, 또는 메뉴 → «저장 및 공유 → 앱으로 설치»
- 화면은 폰에서는 한 줄 카드, 컴퓨터에서는 왼쪽 평면도 + 오른쪽 방 카드로 자동으로 바뀝니다.
- 서비스워커(sw.js)는 화면 껍데기만 보관하고 /api 요청은 저장하지 않습니다.

## 방 배치 (src/rooms.js)

- 치유장비실의 에어컨 4대는 «건강증진실 1»로 표시·제어합니다.
- B1 화장실 옆: 탈의실(여) · 탈의실(남) · 비품실 순.
- 해아림홀(에어컨 2대)은 LG 서버가 제어를 지원하지 않아 `noapi: true` — 일정만 표시하고 제어·자동 제어 대상에서 제외합니다.
