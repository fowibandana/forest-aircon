# 산림치유 에어컨 (ThinQ)

LG ThinQ Connect API(개인 PAT)로 에어컨을 방 단위로 켜기/끄기/점검/온도 설정하는 안드로이드 앱입니다.

## APK 만들기 (GitHub)
1. GitHub에서 새 저장소를 만들고 이 폴더의 모든 파일을 올립니다. (.github 폴더 포함)
2. 저장소의 Actions 탭 → "Build APK" → Run workflow (main에 올리면 자동 실행)
3. 완료되면 실행 결과 화면 맨 아래 Artifacts의 `forest-aircon-apk`를 받아 압축을 풉니다. → app-debug.apk
4. 폰으로 옮겨 설치합니다. ("출처를 알 수 없는 앱 설치" 허용 필요)

## 사용
1. 앱 실행 → ThinQ 토큰 입력 → 토큰 저장 → 기기 불러오기
2. 각 에어컨의 "방 지정"으로 방 이름을 입력 (같은 이름끼리 묶임)
3. 방별/전체 켜기·끄기·점검·온도

## 주의
- 토큰은 앱 안에만 저장됩니다. 채팅 등에 노출된 토큰은 테스트 후 재발급하세요.
- 에어컨이 ThinQ 앱에 등록되어 있어야 목록에 나옵니다.
- 개인 PAT는 개인/비상업 용도 약관이 있습니다.
